Цель: Разработать простое веб-приложение для управления задачами с возможностью добавления, редактирования, удаления и отметки выполненных задач.

Технологии:
Frontend: HTML, CSS, JavaScript
Backend: Python + Flask
База данных: SQLite / MongoDB (на текущем этапе локальное хранилище)

Система контроля версий: Git (GitHub/GitLab)

Управление задачами: Yandex Tracker
